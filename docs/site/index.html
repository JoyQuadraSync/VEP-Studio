Platform capabilities

Infrastructure you can reason about.

Every delivered capability has an explicit owner, deterministic behavior, and automated verification. Planned features remain clearly separated from current functionality.

01

Typed event platform

Validated event intake, typed events, concurrent EventBus publication, stable subscriber identities, and isolated results.

02

Declarative definitions

Immutable versioned workflow graphs, dotted IDs, declarative operation identifiers, and dedicated validation.

03

Deterministic runtime

One incremental advance() contract produces immutable execution snapshots across linear and decision flows.

04

Structured parallelism

Fork/join regions, stable branch IDs, concurrent all-settled rounds, and canonical history aggregation.

05

Persistence boundary

Canonical JSON snapshots, optimistic revisions, duplicate-write protection, explicit save points, and an in-memory reference repository.

06

Exact recovery

Resume orchestration from the latest persisted snapshot using the exact immutable workflow definition ID and version.

Frozen boundary

EventBus publishes events. It does not advance workflow steps, evaluate conditions, select branches, coordinate parallel regions, or store execution state.

Runtime flow

One transition at a time.

WorkflowRunner.advance() is the single progression primitive. Each call returns one new snapshot and never mutates its input.

Linear

02

Decision

Evaluate every condition and select exactly one branch.

03

Fork

Create an ordered active parallel region without running handlers.

04

Parallel round

Advance each incomplete branch at most once using all-settled semantics.

05

Join barrier

Aggregate, retain, flatten history, and complete or fail atomically.

Persistence & recovery

A durable orchestration boundary, without runtime coupling.

Coordinator owns save-point timing. Runner stays storage-free. The in-memory reference repository stores canonical records and rejects stale writes; a process-durable database adapter is planned.
